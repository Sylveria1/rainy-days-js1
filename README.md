# Rainy Days

Rainy Days is a JavaScript 1 course assignment for Noroff.

The project is an interactive online store that fetches product data from the Rainy Days API and displays it dynamically using vanilla JavaScript.

## Features

- Fetches products from the Rainy Days API
- Displays products dynamically on the homepage
- Product detail pages
- Gender filtering
- Men's and women's category pages
- Shopping cart using localStorage
- Cart quantities and total price
- Remove items from cart
- Simulated checkout
- Order confirmation page
- Loading and error states
- Terms and Conditions
- Privacy Policy

## Built With

- HTML
- CSS
- Vanilla JavaScript

## API

Product data is provided by the Noroff Rainy Days API:

`https://v2.api.noroff.dev/rainy-days`
