Privacy Policy

This privacy policy explains how information is handled on this demonstration Rainy Days website.

Personal Information

This student project does not send personal information to a server or store customer details in a database.

Shopping Cart

The shopping cart is stored locally in the user's browser using localStorage. This allows cart contents to remain available while navigating between pages.

Checkout Information

Information entered into the checkout form is used only for the simulated checkout experience and is not submitted or stored.

Third-Party Data

Product data is retrieved from the Rainy Days API provided for this educational assignment.
